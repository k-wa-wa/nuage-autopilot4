# UI設計標準・実装ガイドライン

本プロジェクトの UI は、Nuage エコシステム共通の設計標準に準拠して構築する。
共通のデザイン哲学、デザイントークン体系（カラー、スペーシング、タイポグラフィ、角丸、触覚）、およびガードレール（禁止事項）については、ワークスペース共通ドキュメントを参照すること。

- **共通設計標準**: [`nuage-workspace/docs/ui-design.md`](https://github.com/k-wa-wa/nuage-workspace/tree/master/docs/ui-design.md) (相対パス: `../../nuage-workspace/docs/ui-design.md`)

本ドキュメントでは、本リポジトリ（`nuage-autopilot4`）における実装構成、固有のコンポーネント設計原則、および品質ガードレールの自動検証について定義する。

---

## 1. 実装構成

- **スタイリング手法**: Pure CSS + CSS カスタムプロパティ（CSS Variables）
- **デザイントークン定義場所**: `src/view/styles/global.css` の `:root`
- 各コンポーネントは独立した `.css` ファイルを持ち、共通デザイントークン（`var(--bg)`, `var(--card)` 等）を参照してスタイリングを行う。コンポーネント内での生値の直書きは禁止する。

---

## 2. コンポーネント設計原則（本リポジトリ固有仕様）

### 2.1. Card
- 状態とアクションの最小単位。
- **主アクション**: カード全体をクリックすると該当の GitHub Issue / PR に遷移する。
- **補助操作**: 履歴モーダル表示やチャット調査開始などのサブアクションは、カード内の独立したバッジボタンとして明確にイベント分離する。

### 2.2. Modal / Drawer
- 補助的な詳細情報（エラー原因、エージェント実行履歴、システム情報）の表示に徹する。
- チャット画面（ChatDrawer）はコンテキストを保持したまま調査・指示を行えるサイドパネル／オーバーレイとして振る舞う。
- オーバーレイのクリックまたは右上のクローズボタン（`--scale-icon-active` 適用）で素早く閉じられること。

---

## 3. 品質ガードレールと自動検証（Design Token Lint）

共通設計標準で定められたガードレールを遵守するため、本リポジトリではテストによる自動検証（CI / ローカル）を配備している。

- **テストコード**: `src/view/design-lint.test.ts`
- **実行コマンド**: `bun test src/view/design-lint.test.ts`

### 自動検証される項目
1. **生カラーコードの直書き禁止**: `global.css` 以外での生 `#hex` および有色の `rgba()` / `rgb()` の使用を検知・エラー化。
2. **未定義 CSS 変数の参照禁止**: `var(--...)` で参照された変数が `global.css` に定義されているかを検証。
3. **スペーシング制限**: `padding` / `margin` / `gap` が 4px / 8px グリッド（または 0-2px の極小値）に準拠しているかを検証。
4. **タイポグラフィ階層制限**: `font-size` が許可された階層値（11, 12, 13, 14, 15, 16, 18, 20, 22px）のみであることを検証。
5. **角丸階層制限**: `border-radius` が許可された階層値（0, 4, 6, 8, 12, 14, 16px, 9999px, 50%）であることを検証。
6. **モバイル `:hover` 残留防止**: `:hover` を含むスタイルルールが `@media (hover: hover)` でラップされているかを検証。

※ 意図的な例外が必要な場合は、該当行末に `/* design-lint-ignore */` コメントを付与して明示する。
